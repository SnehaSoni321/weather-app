# 🌦️ Weather App

A simple and responsive Weather App built using **React.js** and the **OpenWeatherMap API**.

## 🚀 Live Demo

👉 https://snehasoni321.github.io/weather-app/

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Current temperature
- 📉 Minimum temperature
- 📈 Maximum temperature
- ⚡ Fast and responsive UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS3
- HTML5
- OpenWeatherMap API

## 📂 Installation

```bash
git clone https://github.com/SnehaSoni321/weather-app.git
cd weather-app
npm install
npm start
```
